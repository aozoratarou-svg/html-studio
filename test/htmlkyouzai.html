ウェブページを作る「3つの魔法」

HTML (骨組み)

ページの「骨組み」！

文字を書いたり、画像を置いたり、ボタンを作ったりするよ。「ここにボタンがあるよ！」とお知らせする係です。

CSS (デザイン)

ページの「デザイン・服」！

文字の色を変えたり、ボタンを丸くしたり、ページをかわいくするよ。「ボタンは赤色で！」と命令する係です。

JavaScript (動き)

ページの「動き・魔法」！

ボタンを押したらガチャが回ったり、計算をしたりするよ。「ボタンが押されたらコレをして！」と動かす係です。

じっけんじょう

下の枠にコードを貼り付けて、「実行（じっこう）する！」ボタンをおしてね。
